# غرفة الهروب الأكاديمية — أكاديمية القاسمي 🧭

تطبيق ويب تفاعلي وتنافسي لفعالية **غرفة الهروب الأكاديمية (Escape Room)** في أكاديمية القاسمي.

## 🌟 مميزات التطبيق
- **شاشة بدء متحركة ثلاثية الأبعاد (3D Ring Carousel)** مع شريط تقدم سلس.
- **تسجيل الفرق والطلاب:** تخصيص اسم المجموعة، عدد الطلاب (2 - 8)، وتخصصاتهم.
- **نظام مسارات عشوائي ذكي (Smart Route Randomization):** توزيع المجموعات على المحطات عشوائياً لمنع التزاحم، مع توحيد المحطة الختامية للجميع في الساحة الرئيسية.
- **شريط تنقل مرئي (Interactive Stepper):** يوضح المحطة الحالية، المحطات المنجزة، وإقفال المحطات القادمة.
- **مؤقت زمني دقيق (Live Timer):** لحساب الوقت المستغرق لكل مجموعة بدقة وتحديد المراكز والأوسمة.
- **المحطات والتحديات التفاعلية:**
  1. منطقة المختبرات (مبنى رقم 5)
  2. غرفة الدكتورة إيناس (رسالة التوقعات في الصندوق)
  3. مركز سويا (تصوير الشيء المميز)
  4. ساحة الكلية (لافتة نوّرت القاسمي)
  5. منطقة غرف المحاضرين (قاعة المناسبات)
  6. الكافيتيريا (جلسة الأريكة)
  7. بيت الطالب (تحدي الألعاب)
  8. المحطة الختامية المشتركة (ساحة القاسمي الرئيسية - مبنى 4)
- **شاشة الفوز والترتيب النهائي:** احتفال بالألعاب النارية (Confetti)، إعلان المركز والوسام المستحق، وملخص إجابات المجموعة وإنجازاتها.

## 🚀 طريقة التشغيل
افتح ملف `index.html` في أي متصفح حديث (Google Chrome, Edge, Firefox, Safari).
